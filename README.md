# Бот «Свет ДТЭК»

Telegram-бот для нескольких человек, отвечает на украинском. Данные берёт со страницы
[ДТЭК Киевские региональные электросети](https://www.dtek-krem.com.ua/ua/shutdowns).

- У каждого пользователя свой список адресов, до 10 штук. Адреса добавляются и удаляются прямо в боте.
- Присылает график по каждому адресу на сегодня и завтра и считает часы со светом и без него.
- Проверяет сайт раз в 2 минуты и присылает график, если он изменился для очереди адреса.
- Предупреждает за 15 минут до отключения и указывает, к какому адресу это относится.
- Показывает аварийное отключение, если сайт указывает его для адреса.

Команды: `/schedule` показывает графики по всем адресам, `/add` добавляет адрес, `/addresses` открывает список адресов.

Нужен Node.js 22 или новее. Сторонних пакетов нет.

## Первый запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Заполните файл `.env` (образец в `.env.example`): `BOT_TOKEN` и `ACCESS_CODE`.
3. Запустите бота:

   ```bash
   node --env-file=.env src/index.js
   ```

4. В консоли появится пригласительная ссылка. Откройте её сами и отправьте тем, кто будет пользоваться ботом.
   Без этой ссылки бот никого не пускает, поэтому не публикуйте её.

## Работа на сервере

Бот должен работать там, где не отключают свет: при отключении дома он перестанет получать изменения.

1. Скопируйте папку на сервер в `/opt/dtek-svet-bot` и положите туда `.env`.
2. Создайте файл `/etc/systemd/system/dtek-svet-bot.service`:

   ```ini
   [Unit]
   Description=DTEK Svet Telegram bot
   After=network-online.target
   Wants=network-online.target

   [Service]
   WorkingDirectory=/opt/dtek-svet-bot
   ExecStart=/usr/bin/node --env-file=.env src/index.js
   Restart=always
   RestartSec=10

   [Install]
   WantedBy=multi-user.target
   ```

3. Включите службу:

   ```bash
   sudo systemctl enable --now dtek-svet-bot
   ```

4. Убедитесь, что сайт ДТЭК отвечает с этого сервера:

   ```bash
   sudo journalctl -u dtek-svet-bot -f
   ```

   В журнале не должно быть строк «Сайт недоступен».

Бот запускайте только в одном экземпляре: Telegram не отдаёт сообщения двум процессам с одним токеном.

## Настройки

Необязательные параметры в `.env`:

| Параметр | По умолчанию | Что задаёт |
| --- | --- | --- |
| `POLL_SECONDS` | `120` | Как часто проверять сайт |
| `WARN_MINUTES` | `15` | За сколько минут предупреждать |
| `DATA_FILE` | `data/state.json` | Где хранить адреса пользователей и последний график |

## Как это устроено

У сайта нет открытого API. Бот делает те же запросы, что и сама страница:
загружает её и спрашивает `/ua/ajax` о новых данных. Страница в браузере делает это раз в 5 минут.
Бот не маскируется под браузер и не обходит защиту. Если сайт перестанет его пропускать,
пользователи получат сообщение об этом через 30 минут, а предупреждения продолжат идти по последнему графику.

- `src/schedule.js`: расчёт интервалов, часов и начала отключений.
- `src/dtek.js`: запросы к сайту.
- `src/app.js`: диалог, уведомления и предупреждения.
- `src/index.js`: запуск и таймеры.
